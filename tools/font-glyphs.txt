# Every character outside ASCII the framework draws, from a string or character
# literal in Sources/TerminalUI (the tutorial's steps included), and how a picture
# of a recording draws it. tools/scripts/check_font_glyphs.py fails when the
# sources and this list disagree; GlyphGeometryTests holds each `shape` entry to
# being one, and each `font` entry to not being one.
#
# `shape`: GlyphGeometry draws it, the same in every format, never from a font.
# `font`: the configured font draws it, so it must be one every monospaced font has,
# or not be drawn at all; say which. Before adding a `font` entry for a mark of the
# framework's own, consider a shape: a fallback font draws at another size.
#
# Format: <U+XXXX or U+XXXX..U+YYYY> <glyph or first..last> <shape|font> <why>

# Whole blocks drawn from geometry.

U+2800..U+28FF ⠀..⣿ shape Braille Patterns, the whole block: 2×4 dots, as BrailleCanvas and the spinners draw them.
